# Лендинг «Северный парк» (OBJ-001) — деплой на Tuqo

Папка `landing\` = готовый сайт: один файл `index.html`, без зависимостей и сборки.

## 1. Локальная проверка (перед деплоем, 2 минуты)

Открыть `index.html` двойным кликом в браузере. Проверить:
- шапка, герой, 3 планировки, калькулятор, форма, футер — всё на месте;
- калькулятор: меняете цену/взнос/срок — платёж пересчитывается; кнопка «Базовая 21,9%» — платёж резко растёт (это фича: показывает ценность семейной ставки);
- форма: если не заполнить имя/телефон — подсветит поля; заполняете — «Заявка принята» (зелёная плашка);
- кнопки ставок и отправка формы пишут `[demo event] lead_submitted` в консоль браузера (F12) — так выглядит событие для пикселя.

## 2. Деплой на Tuqo (5 минут)

1. Регистрация: https://tuqo.ru → «Начать бесплатно» (email + пароль, карта не нужна).
2. «Создать проект» → имя, например `nedvizh-demo` → сайт → «Загрузить папку» → выбрать `landing`.
   Tuqo публикует на `nedvizh-demo.tuqo.ru` с HTTPS автоматически.
3. Открыть сайт, прогнать чек-лист из п.1 ещё раз уже онлайн.

## 3. Форма заявки (после деплоя)

В панели Tuqo у сайта включите «Формы» и создайте форму-приёмник — она даст адрес (endpoint).
Затем в `index.html` в блоке `CONFIG` впишите:

```js
var CONFIG = {
  formEndpoint: "https://api.tuqo.ru/forms/XXXX"
};
```

(точный адрес и формат возьмите из панели Tuqo; до вписывания форма работает в локальном режиме — показывает успех и пишет событие в консоль, ничего не отправляя).

Куда приходят заявки: панель Tuqo, почта или Telegram — выбирается в настройках формы.

## 4. Пиксель Altcraft

В личном кабинете Altcraft создайте пиксель (раздел пикселей/веб-событий) и скопируйте его сниппет.
В `index.html` найдите комментарий `МЕСТО ДЛЯ ПИКСЕЛЯ ALTCRAFT` (в обработчике формы) — вставьте туда код пикселя. Событие `lead_submitted` уже пушится в `dataLayer`.

## 5. UTM

Ссылки на лендинг можно давать с метками, они подхватываются автоматически:
`https://nedvizh-demo.tuqo.ru/?utm_source=email&utm_campaign=m1_winback`
Значения попадают в скрытые поля формы и уедут вместе с заявкой — на демо это история «откуда пришёл лид».

## Что сказать на презентации

Лендинг = источник веб-событий: просмотр страницы (пиксель) и заявка (форма) стекаются в CDP,
дальше — сегменты и механики М1–М4. Формулировка: «сайт — первый источник данных в цепочке
профиль → событие → сегмент → канал».
